## What this is

This is a **consumer awareness project**, not a gambling tool. It's a faithful simulation of how Aviator-style crash betting games work — and how they cheat you.

The demo lets you:
- Place bets and watch the multiplier climb
- Cash out (or not) before the crash
- **See the server's hidden crash point** — decided before the plane even takes off
- Watch how large bets trigger earlier crashes
- Understand the bot manipulation tactics used to build false confidence

---

## The core scam explained

| What you see | What actually happens |
|---|---|
| A plane flying with a rising multiplier | A pre-decided crash point set by the server before takeoff |
| Other players winning big | Bot accounts controlled by the platform |
| Random-looking crashes | An algorithm that crashes early when your bet is large |
| "Provably fair" claims | No verifiable cryptographic proof provided |
| Withdrawal pending | Account suspended until you give up |

## Red flags on real betting platforms

- No cryptographic hash published before each round
- Withdrawal blocked with sudden KYC requests
- App only available as a side-loaded APK (not on Play Store)
- Dozens of "players" always active and winning
- Bonus terms requiring 20–50x wagering before withdrawal
- Telegram groups promising "insider crash points"
